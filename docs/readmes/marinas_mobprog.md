# Facebook Replication (Flutter)

A Flutter UI recreation of Facebook: splash screen, login and register forms, news feed, post details with likes,
notifications and profile. Built for Mobile Programming at National University Manila.

## Features

- Splash, login and register screens with form validation
- News feed of post cards with a like button and image carousel
- Post detail, notifications and profile screens
- Reusable widgets (buttons, dialogs, text fields, info rows)

The app uses sample data only. There is no backend or real authentication.

## Tech stack

Flutter / Dart · cached_network_image · carousel_slider · flutter_screenutil

## Run locally

```bash
flutter pub get
flutter run
```
