# NU Bulldogs Exchange — Shop UI (Flutter)

A Flutter storefront for NU merchandise ("NU Bulldogs Exchange"): home, shop, product details, cart and profile.
Built for a Mobile Programming long exam at National University Manila.

## Features

- Home and shop screens with horizontal and vertical product cards
- Product detail and cart screens
- Profile screen
- Custom Poppins typography and local product images

The app uses local sample data only and has no backend.

## Tech stack

Flutter / Dart · flutter_screenutil

## Run locally

```bash
flutter pub get
flutter run
```
